03 / MASTER EXECUTION

Eksekusi signal

NONAKTIF

Mode live selalu nonaktif saat aplikasi baru dijalankan. Aktifkan setelah Telegram, Gemini, grup sumber, akun utama, dan EA menunjukkan siap.

Live trading punya risiko finansial.EA memakai 0.01 lot tetap, maksimal dua entry, SL dari signal, TP 1:1, dan expiry pending satu jam. BUY memakai BUY LIMIT di bawah harga pasar / BUY STOP di atas; SELL memakai SELL LIMIT di atas / SELL STOP di bawah. Dua entry perlu akun MT5 mode hedging. Uji di akun demo sebelum akun real.
Persiapan MT5 satu kaliTambahkan http://127.0.0.1:8080 di Tools → Options → Expert Advisors → Allow WebRequest for listed URL, lalu aktifkan AutoTrading. Jika koneksi master pertama timeout, jendela terminal portable tetap terbuka untuk pengaturan; setelah allowlist disimpan, sambungkan ulang. Data terminal ada di data/copy-trading/terminals/.
